# Esilogis 🏫🔧

**Esilogis** is a web application built for **l'ESI (École Supérieure d'Informatique)** to manage and streamline maintenance operations across the school.

## 🚀 Overview

Esilogis provides an organized platform for handling facility-related issues (e.g., broken projectors, water leaks, malfunctioning air conditioners, etc.) through a structured role-based system involving administrators, technicians, and regular users (students or staff).

## 👥 Roles & Responsibilities

### 🔑 Admin
The administrator oversees the entire platform and has access to all features:
- Create and manage user accounts
- Add and manage equipment
- Assign tasks to technicians
- Monitor all interventions and activity logs

### 🛠️ Technician
Technicians receive and handle maintenance requests:
- View assigned tasks from the admin
- Mark interventions as complete
- Provide notes or updates on each issue

### 🙋 User
Users can report facility-related problems within the school:
- Submit new intervention requests (e.g., broken data projector, AC issues, water leaks)
- Track the status of their submitted requests

## 📦 Features

- 🧑‍🤝‍🧑 Role-based access and dashboards
- 📝 Equipment management (add, update, delete)
- 🔔 Task assignment and real-time updates
- 📋 Intervention reporting and tracking
- 📊 Admin panel to monitor overall system status
